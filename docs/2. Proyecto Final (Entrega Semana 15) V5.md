## Enunciado

## Solución Tecnológica Software as a Service (SaaS)

## Requerimientos:

- Implemente una Solución Tecnológica Software as a Service (SaaS) en AWS: Multi-tenancy, serverless y basada en eventos.

- Debe tomar como base las funcionalidades según el tipo de SaaS que le toca a su grupo.

- FrontEnd: Use cualquier framework y despliegue en Amplify.

- BackEnd:

- Cree como mínimo 5 microservicios serverless protegidos (Api Gateway, Lambda) cada uno con su propia base de datos (En caso requiera SQL cree un único RDS (https://aws.amazon.com/es/rds/) usando el patrón de diseño BD Multi-tenancy - Patrón 2: Single Database, Multiple Schemas. En caso requiera NoSQL use DynamoDB. Para cada microservicio presente un Diagrama Entidad Relación (SQL) o estructura json (NoSQL)). [URL 🔗](https://aws.amazon.com/es/rds/)

- Cada microservicio debe tener como mínimo 30,000 registros ficticios dividido en 3 tenants.

- Utilice adicionalmente los servicios S3, SNS y SQS.

- Automatice todo el despliegue con framework serverless.

- Presente un Diagrama de Arquitectura de Solución

- Realice la Demo con 2 tenants
